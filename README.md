# 한입 · 韩语口袋

手机优先的韩语复习网页，采用 Material Design 风格，无需注册和安装应用商店 App。

在线使用：**https://wpv-chan.github.io/hangeul-pocket/**

## iPhone 一次添加，以后点图标打开

1. 用 Safari 打开上面的网页。
2. 点「分享」→「添加到主屏幕」。部分 iOS 版本需先展开「更多」。
3. 如有「作为网页 App 打开」选项，保持开启，点「添加」。
4. 第一次保持联网，在网页「设置」里确认「离线内容已准备好」。以后可以从桌面图标直接进入。

如果链接从微信等 App 内打开，请先用 Safari 打开。iOS 的安装步骤需要本人确认，网页不能自动将图标放到主屏幕。

Android：Chrome 菜单 →「安装应用」或「添加到主屏幕」。

官方说明：[Apple：将网站变成网页 App](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios)。

## 学习与分享

- 905 个独立复习项，对应第 1–30 课的 938 条词表记录。9/30 已 OCR 并逐页校对 15 张新照片，新增 661 个复习项；可用「9/30 新增」筛选和练习。
- 闪卡、韩译中、中译韩、拼写、听音、混合测验。
- 分课练习、收藏、错词本、间隔复习、练习续接和学习统计。
- 网页右上角提供分享按钮。分享的是网页链接，不会附带学习进度。
- 浅色与深色主题；首次缓存后支持离线翻卡、选择、拼写及字母示范音。词汇音频听过后缓存；尚未缓存的词汇需联网。

## 学习记录

每个人的记录只保存在当前设备、当前浏览器，不会自动上传或跨设备同步。清除网站数据会清空本地记录；可以在「设置」中导出和导入 JSON 备份。

从旧版 ChatGPT Sites 链接迁移时，请先在旧版导出备份，再在此网页导入。不同网址、不同浏览器，或 Safari 与主屏幕 App 之间，可能有独立存储；按需在目标入口导入备份。

原始照片不在这个仓库中。词库依据两批共 23 张照片整理；新照片补齐第 7 课至第 51 行，并扩展至第 30 课。重复内容合并学习记录；同形词的不同意思分别保留。所有旧词 ID 和存储格式保留，旧版备份可直接导入。

## GitHub Pages 与压缩包

这是纯静态网页，没有服务器、数据库或外部依赖。GitHub Pages 发布来源为 `main` 分支的根目录，`.nojekyll` 禁用 Jekyll 处理。

压缩包用于备份或重新托管，**不是 iOS 安装包**。不建议在「文件」App 里直接打开解压后的 HTML；请使用上面的 HTTPS 网页来保证脚本、存储和离线能力正常工作。

本地预览：

```sh
python3 -m http.server 4173
```

打开 http://localhost:4173。运行 `npm ci && npm test` 验证词库、复习规则、语音、并发保存与离线缓存。测试依赖不会被网页加载。

更新发布后请递增 `sw.js` 中的缓存版本。缓存只清理当前网页路径下的旧缓存，不会清理同账号其他 GitHub Pages 项目的缓存。

## 发音与 iPhone 排查（v1.2.0）

发音使用系统 Web Speech API，点击按钮后直接播放，不自动播放。Safari 的声音列表可能为空或不完整，因此列表中没有韩语声音时也会以 `ko-KR` 尝试播放；iPhone 交由系统按语言选声。每次播放重新读取可用声音，仅在已有播放或挂起队列时取消；保留 utterance 引用，并处理暂停、后台切换、错误与启动超时。

从主屏幕打开时，请联网关闭并重新打开，在「设置」确认最新版本，再点「试听」。页面也提供「检查并加载更新」。若仍无声，先检查媒体音量、蓝牙输出，再在 iPhone 的「设置 → 无障碍（或辅助功能）→ 阅读与朗读（或朗读内容）→ 声音」下载韩语声音，用 Safari 同一网址对比。点「排查发音」可复制浏览器与语音状态，不含学习记录。

语音兼容性修复有模拟回归测试；未在用户的 iPhone 16 / iOS 27 上实测。系统或 WebKit 本身不能启动 TTS 时，网页会显示错误或超时，不保证所有系统语音可用。无需麦克风权限。

页面版本只在「设置」中显示（当前 `1.4.0`）。发布更新时维护 `app.js` 的 `APP_VERSION` / `BUILD_NUMBER` 和 `sw.js` 的缓存版本；数字构建号仅用于发音诊断，不显示在页面底部。

## 韩文字母入门（v1.3.0）

底部导航「字母」及练习首页「开始入门」提供独立的入门路径：

- 认字母：10 个基本元音、11 个组合元音、14 个基本辅音、5 个紧音辅音；普通话近似提示可开关，配口型说明和正常 / 慢速试听。
- 练拼读：可组合全部 19 个初声、21 个元音，并用 7 种基本收尾音体验收音；按 Unicode 韩文音节规则合成，不代替完整音变教学。
- 小测验：看字选示范音罗马字、听音认字、字母闪卡；每轮最多 10 个，结束后可以只练不熟的。听音题排除现代口语常合流的元音干扰项。字母结果、错题、当前测验和学习偏好持久保存，可继续上次或只练易错；不混入词汇统计。

中文提示不是标准音标，不按汉语声调读。辅音以配 `ㅏ` 的完整音节试听，避免语音引擎将单独辅音读成字母名称。字母与罗马字资料参考韩国国立国语院，页面底部提供来源。新模块列入离线预缓存；字母与词汇优先使用随网站提供的合成音频，自由拼读仍可使用设备系统声音。

## 界面图标（v1.3.1）

导航、练习模式、发音、收藏、分享、主题切换及反馈图标统一使用 Google 官方 [Material Symbols Outlined](https://developers.google.com/fonts/docs/material_symbols)（24 px、weight 400、fill 0、grade 0）。`icons.js` 直接内置官方 SVG 图形，随离线资源缓存，不依赖 Google Fonts 联网加载；SVG 以 `currentColor` 适配深浅色主题，按钮的中文无障碍名称保留。

图标来源：[google/material-design-icons](https://github.com/google/material-design-icons/tree/bd8cb85bd4bad964fe6918f79665bb40c3a8efef/symbols/web)。Apache 2.0 许可全文保存在 `licenses/Google-Material-Symbols-LICENSE.txt`。增加图标时应从同一官方系列取原始图形，不自行描画路径。


## 可靠性更新（v1.4.0）

- 进度改用 IndexedDB 事务保存，首次自动迁移旧版 localStorage。按操作合并答题、收藏和设置；同一道题具有唯一事件 ID，不会因两页作答重复累计。多页面通过 BroadcastChannel 同步，重置/导入使用数据代次阻止旧页面恢复旧记录。旧版 localStorage 保留为迁移来源，新版不会再写它。
- 同义拼写按 10 组人工定义的等价词表接受；运动的名词/动词、淋浴/沐浴使用明确题面。原 244 张词卡的 ID、中文释义和主发音保持稳定。
- 复习仅在到期且跨天答对时推进间隔；提前练习不延长到期时间。同日多次答对仍记录练习次数。旧版无法证明跨天复习的掌握等级迁移到至多第 1 阶段，保留次数、正确率和收藏，并在一天内重新安排验证。
- 字母进度、错题、测验续接和偏好纳入保存及 JSON 备份，单独统计；刷新、关闭重开后可继续。
- 928 段合成音频覆盖词汇和字母，约 10.2 MB。字母与入门音节预缓存，词汇按播放缓存，避免首次下载整个音库。音频加载失败可手动改用系统发音；词汇与字母听力都可不计分跳过。来源与音频许可见 [audio/README.md](audio/README.md)。
- Service Worker 优先使用完整版本缓存，避免弱网等待和 5xx 破坏已缓存页面；缓存缺失时设置 4 秒请求超时，写缓存失败不丢弃有效网络响应。音频支持离线 byte-range 请求，兼容 Safari 媒体加载。
- 已做自动回归及本地浏览器验证；用户 iPhone 16 / iOS 27 的硬件播放仍需真机确认。
